# Alinhamento de referências — Shakstory

A página pública do Novelist apresenta uma combinação de escrita rica, comentários, autosave, contadores, histórico de revisão, backup/restauração, metas de palavras, preview integrado, templates e compilação em formatos para leitores e processadores de texto. Também destaca personagens, lugares, cenas e estrutura de capítulos.

A URL brasileira do Kindle Create fornecida pelo usuário retornou uma página de erro 500 durante a consulta. Portanto, nenhum recurso específico dessa página foi tratado como fato verificado. O Shakstory usa a referência funcional solicitada pelo usuário como direção de produto, mas mantém essa limitação documentada.

A direção de fusão adotada para esta iteração é: Novelist para planejamento e organização narrativa; Kindle Create para transformar manuscrito em livro com front matter, sumário, capítulos e exportação; Atticus para presets tipográficos, preview, diagramação e saída multiplataforma. A implementação deve preservar uma fonte semântica única e produzir formatos derivados sem reescrever o manuscrito.
