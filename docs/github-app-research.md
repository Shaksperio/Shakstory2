# Pesquisa de configuração do GitHub App

Consultas realizadas em 26/08/2026 na documentação oficial do GitHub.

A página de registro informa que o App pode ser criado sob uma conta pessoal ou organização. Ela orienta escolher permissões mínimas, configurar Webhook secret quando webhooks estiverem ativos e usar callback apenas quando houver autorização de usuário durante a instalação.

A página de permissões diferencia permissões de repositório, organização, enterprise e conta. Para o Shakstory, o acesso necessário é de repositório, restrito ao repositório privado selecionado; permissões de conta, organização e enterprise não são necessárias.
